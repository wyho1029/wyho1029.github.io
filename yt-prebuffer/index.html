YouTube 全片預載

Brave 插件 · 睇片時喺背後一路預載成條片，快進、倒後都唔使等

⬇ 下載插件（yt-prebuffer.zip）

適用 Brave、Chrome、Edge 等 Chromium 瀏覽器（電腦版）。

佢做咩

YouTube 平時只會預載前面一兩分鐘，你一拉去後面就要等佢再下載。呢個插件會：

  • 一路預載落去：預設預載成條片（可以改做只預載前面 5／10／30／60 分鐘）。
  • 保留已經睇過嘅部分：倒後返去睇唔使重新下載。
  • 喺片左下角顯示進度：例如「⬇ 已預載到 12:40 / 45:00」，載晒會變「✅ 已預載到片尾」。郁滑鼠叫出控制列先會見到。

預載嘅片段只係放喺瀏覽器記憶體，唔會存落硬碟；閂咗分頁就冇。

安裝（大約 1 分鐘）

  1. 撳上面個藍色掣下載 yt-prebuffer.zip，然後解壓，會得到一個 yt-prebuffer 資料夾（入面有 manifest.json）。
    放喺一個唔會刪走嘅位置，例如「文件」；之後唔好搬或者刪，否則插件會失效。
  2. 喺 Brave 網址列輸入 brave://extensions 再撳 Enter。
  3. 打開右上角嘅「開發人員模式」（Developer mode）。
  4. 撳「載入未封裝項目」（Load unpacked），揀啱啱解壓出嚟嘅 yt-prebuffer 資料夾。
  5. 撳工具列嘅拼圖 🧩 圖示，將「YouTube 全片預載」釘選出嚟，撳佢就可以改設定。
  6. 打開（或者重新載入）任何 YouTube 片就生效。

之後有新版：下載新 zip，覆蓋舊資料夾，再喺 brave://extensions 撳插件上面嘅 ↻ 重新載入。

⚠️ 重要：加大 Brave 嘅影片記憶體

唔做呢步，插件只可以預載大約幾分鐘。 Brave（同所有 Chromium 瀏覽器）預設每條片最多留 150MB 畫面 + 12MB 聲音 喺記憶體， 1080p 大約 8 分鐘左右（4K 只有一分鐘幾）。滿咗就會停，片上會顯示「⚠️ 到咗 Brave 記憶體上限」。

解決方法係用兩個啟動參數開 Brave，將上限加大：

你部電腦嘅 RAM建議參數1080p 大約夠幾長
8GB--mse-video-buffer-size-limit-mb=800 --mse-audio-buffer-size-limit-mb=100約 45 分鐘
16GB--mse-video-buffer-size-limit-mb=2000 --mse-audio-buffer-size-limit-mb=200約 1.5–2 個鐘
32GB 或以上--mse-video-buffer-size-limit-mb=4000 --mse-audio-buffer-size-limit-mb=300約 3 個鐘（4K 約半個鐘）

記憶體係播緊嘅片用幾多先佔幾多，唔會一開 Brave 就霸晒。數字唔好超過 4000，超過咗 Brave 會當冇設定。

Windows

  1. 完全閂咗 Brave：右下角系統匣如果有 Brave 圖示，右撳 →「結束」。
  2. 右撳桌面上嘅 Brave 捷徑 →「內容」（Properties）。
  3. 喺「目標」（Target）一欄最尾，brave.exe" 後面加一個空格，再貼上參數（前面嘅路徑唔使改，你部機可能唔同），例如： 
    "C:\Program Files\BraveSoftware\Brave-Browser\Application\brave.exe" --mse-video-buffer-size-limit-mb=2000 --mse-audio-buffer-size-limit-mb=200
  4. 撳「確定」，之後用呢個捷徑開 Brave。如果你平時用工作列（taskbar）個圖示開：右撳工作列 Brave 圖示 → 再右撳彈出嚟嘅「Brave」→「內容」，照樣改一次。

Mac

  1. 完全閂咗 Brave（⌘Q）。
  2. 打開「終端機」（Terminal），貼入以下一行再撳 Enter，會喺「應用程式」整一個「Brave 大記憶體」： 
    mkdir -p ~/Applications && osacompile -o ~/Applications/"Brave 大記憶體.app" -e 'do shell script "open -a \"Brave Browser\" --args --mse-video-buffer-size-limit-mb=2000 --mse-audio-buffer-size-limit-mb=200"'
  3. 之後用 Finder →「前往」→「個人專屬」→「應用程式」入面嘅「Brave 大記憶體」開 Brave（可以拉落 Dock）。
    Brave 已經開咗嘅話參數唔會生效，要先 ⌘Q 閂咗佢。

檢查有冇成功

喺網址列輸入 brave://version，睇「命令列」（Command Line）嗰行有冇 --mse-video-buffer-size-limit-mb。有就得。

要留意

  • 用多咗流量：成條片都會下載，就算你只睇一半。用手機熱點嘅時候可以喺插件熄咗，或者揀「前面 5 分鐘」。
  • 直播唔會預載；首頁滑鼠停喺縮圖嘅預覽都唔會。
  • 插件係靠調整 YouTube 播放器同伺服器之間嘅溝通（SABR 串流）做到。YouTube 日後改咗做法，插件可能會冇效，到時要更新。
  • 呢個係非官方工具，唔會下載片落電腦，亦唔會改廣告或者其他內容。

有問題點算

  • 條片播唔到／黑畫面：撳插件圖示，熄「開啟預載」再重新載入頁面。如果熄咗就正常，再開返預載、改為熄「保留已睇過嘅部分」試吓。
  • 進度一直停喺一兩分鐘：先睇吓有冇「⚠️ 記憶體上限」；冇嘅話可能 YouTube 改咗做法。按 F12 → Console，輸入 __ytpbStats() 再撳 Enter，將結果截圖畀我睇。
  • 想睇詳細記錄：Console 輸入 localStorage.ytpbDebug = '1'，重新載入頁面，就會見到「[YT預載]」開頭嘅記錄。
